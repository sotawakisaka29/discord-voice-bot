# 音声収録サイト

`../relation.csv` の100文章を順番に録音し、44.1kHz・16bit・モノラルのWAVとしてCloudflare R2へ保存するWebサイトです。

保存後の音声も認証付きで試聴でき、同じ文章を再収録して保存すると既存のWAVを上書きします。前後移動に加えて、一覧から任意の文章へ直接移動できます。

`/admin/` には管理者専用画面があり、参加者ごとの進捗と保存済みWAVを確認・試聴できます。参加者フォルダはWAVとプロフィールをまとめたZIPとしてダウンロードできます。一般の招待コードとは別の `ADMIN_PASSWORD` が必要です。

## 保存構造

R2の非公開バケットに、次のキーで保存します。

```text
recordings/<入力された名前>/<セッションID>/_profile.json
recordings/<入力された名前>/<セッションID>/0001.wav
...
recordings/<入力された名前>/<セッションID>/0100.wav
```

セッションIDを挟むことで、同名の参加者や同じ人による再収録で既存データが上書きされるのを防ぎます。

## ローカル確認

1. `.dev.vars.example` を `.dev.vars` にコピーし、3つの値をそれぞれ別の十分に長いランダム文字列へ変更します。
2. R2バケット `voice-recordings` を作成します。
3. `npm install` を実行します。
4. `npm run sync:prompts` を実行します。
5. `npm run dev` を実行します。
6. 表示されたURLの末尾に `?invite=<INVITE_CODE>` を付けて開きます。

## 公開前の確認

- `public/index.html` の同意文を実際の利用目的、保存期間、削除窓口に合わせて確定する。
- R2バケットを公開設定にしない。
- `INVITE_CODE` と `SESSION_SECRET` はCloudflareのSecretとして登録し、ソースやURL以外の公開資料に記録しない。
- `ADMIN_PASSWORD` は招待コードと別の強固な文字列にし、管理者以外と共有しない。
- R2のライフサイクルルールで、説明した保存期間に合わせた自動削除を設定する。
- 収録参加者ごとに異なる招待コードが必要な場合は、公開前に招待管理をD1へ拡張する。
