# Discord Voice Clone Bot Controller

ローカルで運用する Discord Voice Clone Bot と音声サーバーを、ボタン操作で管理する個人用 macOS アプリです。

## 主な機能

- Discord BotとStyle-Bert-VITS2の起動と停止
- 登録済み音声エンジンに応じた一括起動
- 起動プロセスの状態表示と実行ログ
- `.env` の Discord Bot トークン・複数サーバーID設定
- `voices.json` を単一の情報源とした声の一覧表示、デフォルト設定、追加、編集、削除
- クローン音声追加時の利用許可確認
- 学習済みチェックポイントを定型文で一括生成して再生するモデル聴き比べ

## 起動

1. `DiscordVoiceCloneBot.xcodeproj` を Xcode で開きます。
2. 実行先に「My Mac」を選び、Runします。
3. 初回にプロジェクトが自動検出されない場合は、「Bot設定」から `package.json` と `bot.js` があるVoiceBotフォルダを選びます。

アプリから起動したサービスは、アプリ終了時に停止します。Bot設定や声の変更は、次回のBot起動時に反映されます。

声の表示名、ID、エンジン設定、デフォルト選択はすべてVoiceBotプロジェクト直下の`voices.json`から読み込みます。アプリで声を追加・編集・削除した場合も同じファイルへ保存します。アプリに戻ったときと「再読み込み」操作時に最新内容を反映します。

Discord Botは、VoiceBotフォルダ内の`.runtime/node/bin/node`、Apple Silicon Homebrewの`/opt/homebrew/bin/node`の順で互換性のあるNode.jsを自動検出します。音声サーバーはNode.jsを経由せず、既存の起動スクリプトを直接実行します。

「Bot設定」では対象サーバーを1件ずつ追加・削除できます。保存時は `.env` の `DISCORD_GUILD_IDS` にカンマ区切りで記録され、旧 `DISCORD_GUILD_ID` しかないプロジェクトも自動で読み込まれます。

Style-Bert-VITS2を起動する前に`http://127.0.0.1:5000/health`を確認します。すでに別のターミナルや先の実行でサーバーが動いている場合は重複起動せず、「外部で起動中」と表示してそのサーバーを使用します。単一のAPIが `modelId` に応じて複数の声モデルを切り替えます。

Discord Botも `http://127.0.0.1:5001/health` で外部起動を確認します。外部起動中の場合は新しいBotを起動せず、カードから強制停止できます。

「強制停止」を押すと、現在選択中のVoiceBotプロジェクトから起動した対象プロセスだけを特定し、終了します。別のプログラムが同じポートを使っている場合は停止しません。

「モデル聴き比べ」では、`config.json`、`style_vectors.npy`、複数の`*.safetensors`を含む学習結果フォルダを選択します。用意された定型文を全チェックポイントで生成し、同じ画面から順番に再生できます。比較音声は一時フォルダに生成され、元の学習結果とBot用モデル設定は変更しません。

## ローカル運用と安全性

- このアプリは単一ユーザーのMac内で使う前提です。
- 音声APIの登録先は `localhost`、`127.0.0.1`、`::1` に制限しています。
- Discord BotトークンはVoiceBotプロジェクトの `.env` に保存し、画面上では既定で伏せ字にします。
- クローン音声には、自分の声または本人から作成・利用の明確な許可を得た声だけを使用してください。
- ローカルのプロセス実行と設定ファイル更新のため、App Sandboxは無効です。配布用ではなく自分のMac専用として扱ってください。

## コード構成

- `Models/`: 画面区分、サービス、声プロフィールのデータ型
- `Services/`: プロジェクト検出、設定ファイル操作、プロセス管理、共有状態
- `Views/`: ホーム、声の管理、Bot設定、実行ログ、声編集
- `Components/`: 再利用するUI部品
